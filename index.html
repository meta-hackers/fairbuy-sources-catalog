Where FairBuy looks first.

This page is the public, read-only view of the FairBuy discovery source catalog. The FairBuy app fetches sources.json only when an admin clicks Sync from GitHub, validates every entry, and keeps the last-known-good catalog if the fetch fails. Discovery never fetches this page directly. To change the catalog, edit sources.json and open a pull request; CI validates it before GitHub Pages publishes it.
